## The Idea

Snack more, worry less. I sometimes buy snacks I already have or forget to eat them before they expire. This app aims to make it easier to track what is left and reduce food waste.

## Planned Features

- A built-in barcode scanner to identify products using EAN-13 barcodes.
- A database backend to store product information and user settings.
- Automatic notifications when a product is nearing its expiry date.

## Status

This project is ongoing. The features above describe the intended design.
